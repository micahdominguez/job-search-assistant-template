# Packet Writing Training Samples

Use this file to store strong raw examples before distilling them into permanent style rules.

## How To Use

- Add full answers or cover letters that feel authentic.
- Mark what is strong about them.
- Note which truth sources support them.
- Do not copy these word-for-word across companies.
