# Job Packet Generation Instructions

Use these rules when generating application packets, cover letters, recruiter prep, and written answers for the candidate in this repo.

## Core Rule

Prior cover letters are style samples only.

Do not copy or lightly rewrite:

- openings
- closings
- paragraphs
- sentence structure
- transitions
- company-specific claims

## Truthfulness Rule

Only use real, defensible experience from the candidate profile.

Do not:

- invent metrics
- overstate technical depth
- claim quota ownership that did not exist
- answer questions that were not actually asked

## Writing Style

Write clearly, directly, and commercially.

Avoid:

- generic excitement language
- corporate fluff
- overly polished phrasing
- repeated cover-letter structures
- buzzword stacking

## Packet Workflow

Each packet should create:

- `01_fit_analysis.md`
- `02_role_match.md`
- `03_positioning_brief.md`
- `04_cover_letter.md`
- `05_cover_letter_notes.md`
- `06_interview_prep.md`
- `07_application_answers.md`

Keep a compiled `00_packet_bundle.md` as the local tracker and sync artifact.

## Quality Gate

Before finalizing any packet, verify:

- the company is classified from the actual job and company context
- the buyer or user persona matches the posting
- the role-fit language uses actual job-description keywords
- the answer uses real proof from the profile
- the packet sounds like the candidate
- the packet avoids invented experience
- application answers are generated only for captured questions

If any check fails, rewrite before treating the packet as ready.

## Application Questions Rule

When an application asks a written question, include:

- the exact question
- the recommended answer
- why the answer works
- risk level, if relevant
- recruiter-screen risk, if relevant

## Screenshot Rule

If the candidate provides a screenshot:

- extract only what is visible
- answer only visible questions
- do not invent hidden later-step questions
- mark the question status as `Captured from Screenshot`

## Personalization Reminder

This template started from a real working repo. Before relying on packet generation, review `job_search_assistant.py` for candidate-specific fallback story text and refit it to your own background.
